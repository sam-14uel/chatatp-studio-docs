---
title: "Initiate MCP connection OAuth"
description: "Start OAuth authorization for an MCP connection"
api: "POST /v1/mcp/connections/{connection_id}/oauth/initiate/"
---

Requires the `mcp:read` and `mcp:write` scopes. The connection must use `oauth` authentication and its server must have a complete OAuth configuration. Open the returned `authorization_url` in a browser to continue.

<ParamField path="connection_id" type="integer" required>OAuth MCP connection ID.</ParamField>

<ResponseField name="connection_id" type="integer" required>Connection being authorized.</ResponseField>
<ResponseField name="authorization_url" type="string" required>URL to open to authorize the connection.</ResponseField>
<ResponseField name="redirect_uri" type="string" required>Configured OAuth callback URI.</ResponseField>
<ResponseField name="state" type="string" required>Opaque OAuth state token. Keep it private.</ResponseField>
<ResponseField name="expires_at" type="string" required>Expiration time for this authorization flow.</ResponseField>

<RequestExample>
```bash cURL
curl -X POST https://chatatp-agent-builder-backend.onrender.com/v1/mcp/connections/42/oauth/initiate/ \
  -H "Authorization: Bearer $CHATATP_API_KEY"
```
</RequestExample>
