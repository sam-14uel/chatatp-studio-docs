title: Streaming

## Overview

Agents that have `capabilities.streaming: true` support streaming responses via Server-Sent Events. The SDK wraps this into a developer-friendly async iterator.

## Stream a message

```typescript
for await (const event of client.messages.stream(91, { content: "Hello" })) {
  switch (event.type) {
    case "message.created":
      console.log("User message stored:", event.data);
      break;
    case "tool.execution.completed":
      console.log("Tool ran:", event.data);
      break;
    case "agent.response.completed":
      console.log("Agent replied:", (event.data as any).content);
      break;
    case "completion.completed":
      console.log("Stream complete.");
      break;
  }
}
```

## Use the high-level interface

```typescript
for await (const event of client.chatStream({
  agent_id: 7,
  external_user_id: "user_12345",
  message: "Summarize the return policy.",
})) {
  if (event.type === "agent.response.completed") {
    console.log(event.data);
  }
}
```

## Event types

| Event | When it fires |
|---|---|
| `conversation.message.created` | Stream accepted, user message creation has started |
| `message.created` | User message stored successfully |
| `tool.execution.completed` | A tool call completed and is visible to your app |
| `agent.response.completed` | The final Agent message was stored |
| `completion.completed` | Stream is fully complete |

## Error handling during streaming

The SDK surfaces stream errors as standard SDK exceptions:

```typescript
import { NetworkError, TimeoutError } from "@chatatp/studio";

try {
  for await (const event of client.messages.stream(91, { content: "Hello" })) {
    // handle events
  }
} catch (err) {
  if (err instanceof TimeoutError) {
    console.error("Stream timed out:", err.message);
  } else if (err instanceof NetworkError) {
    console.error("Connection dropped:", err.message);
  } else {
    throw err;
  }
}
```
