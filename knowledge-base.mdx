---
title: Knowledge Bases
description: Create, populate, attach, and query knowledge bases with the SDKs and CLI
---

The Python and JavaScript SDKs expose knowledge-base operations through `client.knowledge_bases`. The Studio CLI exposes the same management workflow through `studio kb` and uses the authenticated `/dapi/` endpoints used by the Studio frontend.

## Python SDK

```python
from chatatp_studio import ChatATPClient

async with ChatATPClient(api_key="chatatp_sk_...") as client:
    knowledge_bases = await client.knowledge_bases.list()
    knowledge_base = await client.knowledge_bases.create(
        "Product docs",
        description="Support documentation",
        agent_id=7,  # optional: attach while creating
    )

    await client.knowledge_bases.upload(knowledge_base["id"], "./manual.pdf")
    await client.knowledge_bases.add_url(
        knowledge_base["id"],
        "https://docs.example.com",
    )
```

## JavaScript SDK

```typescript
import { ChatATPClient } from "@chatatp/studio";

const client = new ChatATPClient({ apiKey: "chatatp_sk_..." });
const knowledgeBases = await client.knowledgeBases.list();
const knowledgeBase = await client.knowledgeBases.create({
  name: "Product docs",
  description: "Support documentation",
  agent_id: 7, // optional: attach while creating
});

await client.knowledgeBases.upload(
  knowledgeBase.id,
  new Blob(["Product information"], { type: "text/plain" }),
  "product.txt",
);
```

## Upload and monitor documents

```python
documents = await client.knowledge_bases.documents(knowledge_base_id)
stats = await client.knowledge_bases.stats(knowledge_base_id)

for document in documents["data"]:
    print(document["name"], document["status"], document["chunk_count"])
```

Uploads are indexed asynchronously. Poll documents or stats until the document reaches `indexed` or `failed`. The response includes `chunk_count`, `char_count`, and `error_message`.

## Query and attach

```typescript
const result = await client.knowledgeBases.search(
  knowledgeBase.id,
  "How do I reset my password?",
  5,
);
console.log(result.context, result.has_context);

await client.knowledgeBases.attach(7, knowledgeBase.id, {
  enabled: true,
  auto_context: true,
  max_context_chunks: 5,
  context_threshold: 0.3,
});
```

Use `addUrl()` to index a site. Crawling is asynchronous:

```python
await client.knowledge_bases.add_url(knowledge_base["id"], "https://docs.example.com")
```

## CLI

```bash
studio kb list
studio kb create --data '{"name":"Product docs","description":"Support docs"}'
studio kb documents upload <knowledge-base-id> --file ./manual.pdf
studio kb documents list <knowledge-base-id>
studio kb domains add <knowledge-base-id> --url https://docs.example.com
studio kb stats <knowledge-base-id>
studio kb search <knowledge-base-id> --query "reset password"
studio kb agent attachments attach <agent-id> --kb-id <knowledge-base-id>
```

The CLI commands use the same session/token-authenticated `/dapi/knowledge-bases/` and `/dapi/agents/{agent_id}/knowledge-bases/` resources as the frontend.
