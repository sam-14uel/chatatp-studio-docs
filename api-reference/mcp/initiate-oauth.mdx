---
title: "Initiate MCP server OAuth"
description: "Start OAuth authorization for an MCP server and create its connection after callback"
api: "POST /v1/mcp/oauth/initiate/"
---

Requires the `mcp:read` and `mcp:write` scopes. The server must be accessible to the API key, use `oauth` authentication, and have a complete OAuth configuration. Open the returned `authorization_url` in a browser to continue. The OAuth callback creates the account or team connection after authorization succeeds.

<ParamField body="server_id" type="integer" required>MCP server ID.</ParamField>
<ParamField body="redirect_uri" type="string">Optional OAuth callback URI. Defaults to the URI configured for the server.</ParamField>

<ResponseField name="authorization_url" type="string" required>URL to open to authorize the server connection.</ResponseField>
<ResponseField name="redirect_uri" type="string" required>Configured OAuth callback URI.</ResponseField>
<ResponseField name="state" type="string" required>Opaque OAuth state token. Keep it private.</ResponseField>
<ResponseField name="expires_at" type="string" required>Expiration time for this authorization flow.</ResponseField>

<RequestExample>
```bash cURL
curl -X POST https://chatatp-agent-builder-backend.onrender.com/v1/mcp/oauth/initiate/ \
  -H "Authorization: Bearer $CHATATP_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "server_id": 12 }'
```
</RequestExample>
