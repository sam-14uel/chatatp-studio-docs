title: Installation
description: Install the chatatp-studio package
---

## Requirements

- Python 3.10 or later
- [`httpx`](https://www.python-httpx.org/) (installed automatically)

## pip

```bash
pip install chatatp-studio
```

## uv

```bash
uv add chatatp-studio
```

## poetry

```bash
poetry add chatatp-studio
```
